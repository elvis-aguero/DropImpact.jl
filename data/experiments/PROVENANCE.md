# Provenance of the files in `data/experiments/`

Read this before quoting any number from here. The files fall into three classes and only one of
them is experimental data.

## 1. Experiment — the only validation target

| File | Points | Bo | Oh | Source |
|---|---|---|---|---|
| `bath_experiment_water.csv` | 5 | 0.017 | 0.006 | `water_QPExp_DNS_3panel_FFF.fig` |
| `bath_experiment_oil.csv` | 12 | 0.056 | 0.058 | `oil_3panel_FINALF.fig` |

Extracted by `scripts/extract_bath_experiment.m` from the `errorbar` objects of the authors' MATLAB
figure files (Alventosa, Cimpeanu & Harris, *Inertio-capillary rebound of a droplet impacting a
fluid bath*, JFM 958 A24, 2023; doi:10.1017/jfm.2023.88). Each point is one `errorbar` object with
a symmetric ± delta — the standard deviation over at least five trials, per the figure captions —
and the same `We` values appear in all three panels of each figure (α, t_c, δ), which is the
structure of a single experiment measured three ways.

These points are absent from the digitised CSV export that already existed in the source
repository, because an export that walks only `line` children discards every `errorbar` object.
That export contains the figures' model curves and none of the measured points.

### What is verified

- The `(Bo, Oh)` printed in the captions are reproduced to 0.2–0.3 % by this package's fluid
  presets, built from the paper's own table 1 — asserted in `test/test_fluids.jl`.
- The oil set's highest point, `We = 7.307001`, requires `V0 = 66.8 cm/s` at `R = 0.35 mm`, inside
  the tabulated `20–100 cm/s`; the tabulated `We` range is `0.5–8.0`.
- The published curves' trend against these points matches the paper's own text: its
  quasi-potential model underpredicts `t_c` and `δ` at intermediate `We`.

### What is NOT verified — and it matters

**The published figures are `water_QPExp_DNS_3panel_FINAL2.pdf` and
`oil_QPExp_DNS_3panel_FINAL2.pdf`. The `.fig` files read here are named `..._FFF.fig` and
`..._FINALF.fig`.** The names do not match, and the PDFs are not present in any repository
available here, so it cannot be confirmed that these are the *published* data rather than a draft
or an extended version.

There is also no raw per-trial oil data to cross-check against. `DataForReboundsOnly.xlsx`, which
sits beside the figures, is a single **different** fluid — `μ = 1.74e-3 Pa·s`, `σ = 0.0187 N/m`,
i.e. roughly 1.8 cSt rather than 5 — so it corroborates nothing about these twelve points, even
though it does reach `We = 7.76` and shows that high-`We` oil rebounds were measured by this group
at some viscosity.

**Consequence.** Conclusions that rest on the experimental *values* — notably the maximum-deflection
deficit at oil `We ≥ 3.9` — inherit this uncertainty and should be checked against the published
PDF before being asserted. Conclusions about the *solver* do not: that `selector = :feasible` loses
contact after `0.194` and lets the droplet sink at `We = 7.307` is a property of the code at that
`(We, Bo, Oh)`, whatever the measured contact time there turns out to be.

## 2. Model output — cross-checks, not validation

| File | What it is |
|---|---|
| `bath_km_contact_time.csv` | Verbatim copy of `lowWeberComparison.csv`: 153 runs of the reference implementation. **No experiment column at all** — `N = 60` is a mode count, so every row is model output. Supports a code-to-code cross-check and nothing stronger. |
| `bath_model_curves_{water,oil}.csv` | The 1PKM (blue solid) and DNS (black dashed) curves from the same three-panel figures, all three metrics, extracted by `scripts/extract_bath_model_curves.m`. Used to ask whether a residual here is specific to this package or shared with the published reduced model. |
| `model_vs_experiment_*.csv` | Generated by `scripts/compare_fluid_experiment.jl`; gitignored, uploaded as a CI artifact. |

## 3. A DIFFERENT PHYSICAL PROBLEM — never mix these with the above

| File | What it is |
|---|---|
| `SOLID_SUBSTRATE_contact_time_vs_we.csv` | Droplet onto a **rigid wall**, not a bath. |
| `SOLID_SUBSTRATE_cor_vs_we.csv` | Same. |
| `SOLID_SUBSTRATE_contact_radius_timeseries.csv` | Same. |

From `LowWeberDropRebound`, whose README opens "MATLAB scripts for simulating the dynamics of
liquid droplets impacting **solid substrates**". On a rigid wall the rebound is set by the drop's
own `l = 2` free oscillation — full period `2π/√8 = 2.2214 t_σ`, classical superhydrophobic value
≈ 2.6 `t_σ` — and these files span `1.96…3.36`. A bath deforms and carries impact energy away as
interfacial waves, so contact lasts markedly longer: `4.44…8.09`. **The two bands are disjoint**,
so no parameter matching reconciles them, and `test/test_bath_reference.jl` asserts that
disjointness. Mistaking one for the other produced a spurious "2× contact-time overprediction" that
was pursued as a model defect for several rounds. `scripts/compare_experiments.jl` refuses to run
against them without `--allow-solid-substrate`.

`rebound_low_weber_raw.csv` is **not** in this class despite the similar name — it comes from the
bath repository. It is broad CoR-only data with no contact time.
